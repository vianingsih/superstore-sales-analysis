# superstore-sales-analysis
Project ini adalah tugas praktik mandiri untuk Mini Bootcamp Finance. Dashboard ini dibuat menggunakan React dan Tailwind CSS untuk menganalisis data penjualan dari dataset Sample Superstore.



🚀 Fitur Utama

  Interactive Slicers: Filter data berdasarkan Region, Kategori, dan Tahun secara real-time.

  Pivot Table Analysis:

   Penjualan per Region (Bar Chart).

   Analisis Profit per Sub-Kategori (Tabel dengan Conditional Formatting).

   Tren Penjualan & Profit Tahunan (Line Chart).

   KPI Dashboard: Menampilkan Total Sales, Total Profit, dan Average Profit Margin.

   Data-Driven Insights: Executive summary otomatis berdasarkan filter yang dipilih.



📁 Struktur File

  superstore_dashboard.jsx: File utama kodingan dashboard (React).

  Sample - Superstore.csv: Dataset sumber yang dianalisis.

  README.md: Dokumentasi project ini.



🛠️ Teknologi yang Digunakan

  React.js

  Recharts (Untuk visualisasi data)

  Lucide React (Untuk ikon dashboard)

  Tailwind CSS (Untuk styling UI)
